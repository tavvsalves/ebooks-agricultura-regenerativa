# Política de versões

## URL permanente da obra

A página abaixo deve permanecer estável e apontar sempre para a edição corrente:

https://tavvsalves.github.io/ebooks-agricultura-regenerativa/solo-que-segura-a-safra/

## Versões publicadas

- **latest**: edição corrente.
- **v1.0, v1.1, v1.2...**: versões publicadas e congeladas.
- **v2.0, v3.0...**: novas edições com mudanças substantivas.

Uma versão publicada não deve ser sobrescrita. Correções ou ampliações devem gerar nova versão.

## Citação

A citação deve indicar a versão consultada quando a primeira edição formal for disponibilizada.
